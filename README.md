# StudentPortalMVC - ASP.NET Core MVC Application with Authentication

## Project Overview

StudentPortalMVC is an ASP.NET Core MVC application developed to implement user authentication using ASP.NET Core Identity. The application allows users to securely register, log in, log out, and access protected pages. It demonstrates how authentication and authorization are implemented in an MVC application while following the MVC architecture.

---

## Purpose of the Project

The purpose of this project is to understand and implement authentication in an ASP.NET Core MVC application. It provides a secure login system where only authenticated users can access authorized pages. This project also helps in learning the integration of ASP.NET Core Identity with the MVC framework.

---

## Features

- User Registration
- User Login
- User Logout
- Authentication using ASP.NET Core Identity
- Authorization using the `[Authorize]` attribute
- Protected Dashboard accessible only to authenticated users
- MVC (Model-View-Controller) Architecture
- Secure user authentication and session management
